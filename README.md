One entry for make.fun's "Six Words, One Story" bounty: a lighthouse keeper's last night, told in exactly six words — "His last light outlived him, burning." The keeper is gone; the light he tended keeps burning, outliving the man who kept it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the six-word story to `/output/entry.txt`.
